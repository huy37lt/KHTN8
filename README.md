# Đề Cương Ôn Tập Giữa Học Kì I Môn KHTN 8 - Lớp 8B
### Trường THCS Bát Tràng (Năm học 2026 - 2027)

Ứng dụng web luyện thi, ôn tập lý thuyết trọng tâm và rèn luyện kỹ năng trắc nghiệm dành cho học sinh Lớp 8B trường THCS Bát Tràng.

---

## 🌟 Tính Năng Nổi Bật

1. **Toàn Bộ Nội Dung Đề Cương Chính Thức:**
   - **55 Câu Trắc Nghiệm 4 Phương Án:** 15 câu Vật Lý (Bài 1, 13, 14), 25 câu Hóa Học (Bài 2, 3, 4, 5, 6), 15 câu Sinh Học (Bài 30, 31, 32).
   - **30 Câu Trắc Nghiệm Đúng / Sai:** Rèn luyện tư duy phân tích nhận định khoa học.
   - **30 Câu Hỏi Trả Lời Ngắn:** Ôn tập công thức, quy tắc đổi đơn vị và định nghĩa nhanh.
   - **9 Bài Tập Tự Luận Có Hướng Dẫn Giải Chi Tiết:** Gồm các bài toán định lượng và phương án thực hành thí nghiệm.

2. **Chế Độ Luyện Tập Đa Dạng:**
   - **Ôn từng câu:** Biết ngay kết quả Đúng/Sai tức thì kèm lời giải thích chi tiết.
   - **Thi thử bấm giờ:** Mô phỏng phòng thi thật với đồng hồ đếm ngược, phiếu trả lời trắc nghiệm chuẩn.
   - **Xáo trộn ngẫu nhiên:** Trộn thứ tự câu hỏi và thứ tự các đáp án A, B, C, D để tránh học vẹt.
   - **Sổ câu sai:** Tự động lưu các câu làm sai để học sinh luyện lại cho đến khi đạt điểm 10.

3. **In Ấn & Xuất Bản Đề Thi A4:**
   - Hỗ trợ giáo viên in đề kiểm tra kèm bảng đáp án và hướng dẫn giải để phát cho học sinh làm bài trên giấy.

---

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ (Local)

Yêu cầu: Đã cài đặt [Node.js](https://nodejs.org/) (phiên bản 18 trở lên).

```bash
# 1. Cài đặt các gói phụ thuộc
npm install

# 2. Khởi chạy môi trường phát triển
npm run dev

# 3. Đóng gói bản phát hành (Production build)
npm run build
```
